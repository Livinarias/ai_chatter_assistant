🔒 Data Transparency & Privacy Statement

This module connects directly and exclusively from your Odoo server to your chosen AI provider's official API endpoint (OpenAI, Anthropic, DeepSeek, or OpenRouter) using your own API credentials.

  • No Middleman Servers: All requests travel point-to-point directly between your Odoo server and the AI API.
  • Encryption at Rest: All API keys are encrypted with symmetric AES-128 Fernet encryption before being stored in the database.
  • User Consent: AI features are triggered strictly on-demand by user clicks. No background scraping or unsolicited data transmission occurs.

Frequently Asked Questions

Everything you need to know about AI Chatter Assistant.

Which AI providers are supported?

You can connect to OpenAI (GPT-4o, GPT-4o-mini), Anthropic Claude (3.5 Sonnet, 3.5 Haiku), DeepSeek (Chat/V3), or OpenRouter (giving you access to 100+ open-source models including Llama 3, Mistral, and Nemotron).

Is my company data sent to third parties?

Requests are transmitted directly from your Odoo server to your chosen AI provider's official endpoint via secure HTTPS using your own API credentials. There are no middleman proxy servers, telemetry trackers, or external databases.

What is the difference between Simple and Secure encryption?

Simple Mode: An AES-128 Fernet key is generated automatically and stored in Odoo System Parameters. Great for quick zero-config setup.
Secure Mode: The master encryption key is supplied exclusively via an operating system environment variable (AI_ENCRYPTION_KEY), ensuring the key never touches database storage.

Does this work across all Odoo records?

Yes. Because it hooks into Odoo's core mail.thread mixin, the AI assistant buttons appear automatically on any model equipped with Chatter (Contacts, CRM Leads, Sales Orders, Invoices, Project Tasks, Helpdesk, and custom addons).
